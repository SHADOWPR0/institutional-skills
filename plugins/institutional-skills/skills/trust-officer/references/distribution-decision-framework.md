# Distribution Decision Framework

## Decision Inputs

- governing distribution standard (mandatory/discretionary)
- beneficiary need profile and prior pattern
- trust liquidity and portfolio impact
- tax consequences to trust and beneficiary
- fairness/impartiality considerations

## Standard Workflow

1. classify request (health, education, maintenance, support, discretionary)
2. confirm authority and restrictions
3. evaluate amount, timing, and source of funds
4. run impartiality and precedent checks
5. approve, modify, defer, or decline with written rationale

## Documentation Minimum

- request summary
- facts reviewed
- fiduciary rationale
- approvals and dissent notes
- post-decision monitoring items
