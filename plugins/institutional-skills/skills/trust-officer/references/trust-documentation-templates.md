# Trust Documentation Templates

## A) Fiduciary Decision Memo

- case identifier and date
- governing authority and constraints
- facts and evidence reviewed
- options considered
- selected action and fiduciary rationale
- approvals, conditions, and monitoring

## B) Distribution Case Record

- request details
- standard applied
- financial/tax impact summary
- decision and rationale
- communication log

## C) Exception Remediation Log

- exception description
- severity and owner
- corrective actions
- target completion date
- closure evidence
