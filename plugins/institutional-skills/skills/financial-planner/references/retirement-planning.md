# Retirement Planning

## Accumulation Phase

- required savings path vs goal
- contribution prioritization by account type
- glide-path and risk-budget alignment

## Distribution Phase

- withdrawal sequencing and sustainability
- inflation, longevity, and healthcare stress tests
- guardrail spending framework under poor market regimes

## Metrics

- probability of plan success (assumption-based)
- withdrawal rate vs sustainability range
- funded status by milestone year
