# Follow-Up Template

Use after no response, after a meeting, or when reviving a thread.

## Gentle Follow-Up

Hi {{recipient_name}},

One useful addition since my last note: {{new_fact_proof_or_artifact}}.

It sharpens the case for {{company_or_topic}} because {{main_reason}}.

Useful if I send {{artifact_or_next_step}}?

Best,  
{{user_name}}

## Stronger Follow-Up

Hi {{recipient_name}},

{{new_evidence_or_changed_context}}.

That matters because {{core_conviction}}. The strongest proof is {{best_evidence}}.

Worth looking at {{useful_offer_or_artifact}}?

Best,  
{{user_name}}

## After Meeting

Hi {{recipient_name}},

Thanks again for taking the time today.

The key point is {{key_takeaway}}. {{new_fact_or_clarification}}.

I will {{owned_next_step}} by {{date_or_condition}}.

Best,  
{{user_name}}

## Rule

Every follow-up must add a new fact, proof point, useful artifact, changed condition, or sharper angle. If nothing new exists, use one brief close-the-loop note or wait. Never send an empty reminder.
