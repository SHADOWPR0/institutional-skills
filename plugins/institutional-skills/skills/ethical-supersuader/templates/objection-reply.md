# Objection Reply Template

Use when the recipient has raised a concern.

## Structure

Hi {{recipient_name}},

I think that is a fair concern.

The way I would separate it is this: {{distinction_that_clarifies_the_issue}}.

If the question is {{version_of_objection}}, then I agree {{acknowledgment}}. But if the question is {{better_framed_question}}, then I think the answer is more interesting.

What gives me comfort is {{evidence_or_reasoning}}.

The risk is still {{remaining_risk}}. I would not hand-wave that away. But I also do not think it should obscure {{larger_point}}.

My read is that this is worth {{recommended_next_step}}, not because it is fully de-risked, but because {{why_worth_attention_anyway}}.

Best,  
{{user_name}}

## Tone

Respect the objection.  
Do not sound defensive.  
Make the recipient feel smarter for having raised it.
