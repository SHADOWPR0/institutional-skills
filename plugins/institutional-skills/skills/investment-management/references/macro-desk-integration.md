# Macro Desk Integration

`global-macro-theme-picker` is the default Macro Desk package inside the
investment-management family.

## Boundary

- Keep `{SKILLS_ROOT}/global-macro-theme-picker` unchanged as
  the canonical macro package.
- Keep `{SKILLS_ROOT}/global-macro-theme-picker` available as
  the global callable runtime path.
- Keep Drive and private Git mirrors byte-identical.
- Keep downstream projects wired to the same top-level package from their own project-side skill locks.

This integration file exists so the Macro Desk appears inside the
asset-management org without copying, renaming, or weakening the standalone
package that locked integrations depend on.

## Invocation

Use `global-macro-theme-picker` for:

- quarterly zero-based macro rebuilds
- shared world-state snapshots
- macro thesis cards
- expression comparison
- price-aware entry states
- proposed paper macro books
- monthly evidence checks
- event-driven macro reviews
- sanitized locked-consumer macro theme handoffs

Return to `investment-management` for:

- mandate fit
- live capital allocation
- final portfolio construction
- sizing approval
- execution approval
- cross-desk conflicts

## Output Routing

- Full macro research output can include expression comparison and paper-book
  recommendations with approval state.
- Theme-handoff output must stay theme-level and sanitized: no securities,
  tickers, weights, order instructions, sizing, entry/exit levels, or execution
  language.
- Every macro output must preserve the shared snapshot, evidence freshness,
  invalidation, bear case, crowding, and data-gap requirements from the macro
  package itself.
