# Tax Formulas and Metrics

## Core Metrics

- Effective Tax Rate (ETR) = Tax Expense / Pre-Tax Income
- Cash Tax Rate = Cash Taxes Paid / Pre-Tax Income
- Tax Variance = Actual Tax - Forecast Tax
- After-Tax Return = Pre-Tax Return * (1 - Tax Rate)

## Planning Use

- compare alternatives on after-tax basis
- isolate timing effects vs permanent effects
- track forecast error and improve assumptions
