# Curated Sales Plugin Support Map

Use this file when `growth-operating-system` needs tactical sales, CRM,
meeting, account-research, or pipeline-support discipline from the bundled
OpenAI Sales plugin.

This file is a support map, not a new front door. `growth-operating-system`
remains the decision owner for market intelligence, offer, positioning,
campaign economics, funnel design, copy strategy, lifecycle, referral systems,
growth analytics, and kill rules.

## Operating Rule

1. Start in `growth-operating-system`.
2. Define ICP, offer, growth equation, funnel stage, metric, and stop rule.
3. Load only the Sales plugin specialist file that improves the current
   deliverable.
4. Borrow execution checklists, account-research structure, CRM field discipline,
   meeting prep, and forecast-review patterns.
5. Do not let CRM connector availability define strategy.
6. Do not send outreach, update CRM records, or launch a campaign without
   explicit authority and compliance fit.
