# Deprecated Growth Skills

Deprecated here means "not a strategic front door." It does not mean delete.

## Keep As Support Modules

### CRM Connectors

HubSpot, Attio, Capsule, Pipedrive, Close, Zoho, Salesmate, noCRM, CentralStationCRM, Dynamics, Kommo, Apollo CRM-like functions.

Use for:

- contact/deal retrieval
- pipeline updates
- activity logging
- task creation
- contact/company search

Do not use for:

- ICP strategy
- offer strategy
- funnel architecture
- attribution decisions

### Email/SMS/Outreach Connectors

Instantly, Lemlist, ActiveCampaign, SendGrid, Postmark, SMTP2GO, MailerSend, EmailOctopus, Benchmark Email, Omnisend, Customer.io, Twilio SMS, Campaign Cleaner, Emaillistverify.

Use for:

- campaign setup
- delivery data
- list hygiene
- contact sync
- template operations

Do not use for:

- unverified claims
- unsupported scarcity
- spammy campaigns
- strategy without opt-out/compliance checks

### SEO/Content Tools

Ahrefs, SEMrush, technical SEO checker, on-page SEO auditor, content-quality auditor, SEO content writer, entity optimizer, internal-linking optimizer, domain authority auditor.

Use for:

- channel-specific audit
- keyword/backlink/page diagnostics
- technical and content fixes

Do not use for:

- replacing business-level growth prioritization

### Narrow Copy/Brand/Social Tools

Brand analyzer, social media generator, Twitter optimizer, content creator, pitch deck, theme factory.

Use for:

- channel-specific packaging
- artifact generation

Do not use for:

- deciding the offer, ICP, or funnel economics.

## Deletion Policy

Do not delete any deprecated-support skill without:

1. backup
2. manifest entry
3. replacement route
4. user approval
