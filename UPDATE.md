# Updating

Releases are deterministic exports from one maintained core. Verify PUBLIC_BUILD.json hashes, review source gates, and run `python3 -B -m unittest discover -s tests` before upgrading. Run `python3 install.py --target <same-directory>`; unchanged managed files update, recipient edits cause a conflict rather than being overwritten, and bindings.json is preserved. No scheduler is installed. Candidate learning requires observed evidence, baseline/challenger evaluation and owner review; the journal never rewrites analytical methods automatically.
